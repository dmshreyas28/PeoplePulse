# Sample HR Attrition Dataset

This is a sample dataset for testing the PeoplePulse attrition prediction model.

## Dataset Information

- **Source**: IBM HR Analytics Employee Attrition & Performance (sample subset)
- **Records**: 15 sample employees
- **Purpose**: Development and testing

## Features

### Demographics
- Age
- Gender
- MaritalStatus
- DistanceFromHome

### Employment
- Department
- JobRole
- JobLevel
- YearsAtCompany
- YearsInCurrentRole
- YearsSinceLastPromotion
- YearsWithCurrManager
- NumCompaniesWorked

### Compensation
- MonthlyIncome
- PercentSalaryHike
- StockOptionLevel

### Satisfaction & Performance
- JobSatisfaction (1-4)
- EnvironmentSatisfaction (1-4)
- RelationshipSatisfaction (1-4)
- WorkLifeBalance (1-4)
- PerformanceRating (3-4)

### Work Characteristics
- BusinessTravel
- OverTime
- TrainingTimesLastYear

### Target
- **Attrition**: Yes/No (whether employee left the company)

## Usage

For a full dataset, download the IBM HR Analytics dataset:
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

Place the full dataset here for production training.

## Note

This sample data is for demonstration purposes only. Do not use real employee data without proper anonymization and consent.
